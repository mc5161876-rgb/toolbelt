# Toolbelt Chrome extension

1. Start or install the Toolbelt desktop app.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose this `extension` folder.
5. Pin the Toolbelt icon from Chrome's Extensions menu.

The popup saves the current page and your personal “Use this when…” reason. If the desktop app is closed, the capture remains in Chrome's local outbox and retries automatically.
